# Maine Conditions

A small project for learning the API loop: ask a computer for data, read the JSON answer, and show it on a page.

## What I'm learning

1. Fetch data from an API (Open-Meteo weather — free, no key needed)
2. Read the JSON answer it sends back
3. Pull out the parts I care about and display them in plain English

## Structure

- `weather.py` — the script that reads raw weather data and prints it
- `data/` — raw API responses (exactly what the computer sent back)
